# AsterCommunity Homebrew Tap

Homebrew tap for AsterCommunity command-line tools. Formulas are updated automatically by each project's release pipeline whenever a version tag is published.

## Formulae

### aster-acme

Embeddable Rust ACME client and CLI for automated certificate issuance.

```sh
brew install astercommunity/tap/aster-acme
```

Prebuilt binaries are provided for macOS (Apple Silicon and Intel) and Linux (amd64 and arm64).
